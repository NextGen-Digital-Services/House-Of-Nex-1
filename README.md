# House of Nex — NEXGIFTING + Events (Premium Website Build)

"We create experiences people remember."

House of Nex is a premium creative studio operating across two connected verticals:
1. **Events & Experiences** (Corporate Summits, Kids & Family Birthdays, Theme Décor, Experiential Setups)
2. **Corporate Brand Experiences** (Festive & Executive Gifting, Branded Lifestyle Merchandise, Employee/Event Kits, Custom Uniforms & Apparel)

---

## 🎨 Design System — "Amalfi Gold" Palette

- **Base / Background:** Warm Ivory (`#F8F3EA`)
- **Surface:** Soft Cream (`#F1E9DA`)
- **Primary Accent:** Deep Terracotta (`#B5502E`)
- **Secondary Accent:** Antique Gold (`#C6A15B`)
- **Tertiary Accent:** Deep Olive / Sage (`#6B7255`)
- **Text Headings:** Espresso Charcoal (`#241D19`)
- **Text Body:** Warm Charcoal (`#4A423C`)
- **Dividers & Borders:** Muted Sand (`#DCD0BC`)

**Typography:**
- **Headings:** Google Font `Fraunces` (serif)
- **Body & UI:** Google Font `Manrope` (sans-serif)

---

## 🚀 Tech Stack

- **Framework:** React + Vite
- **Language:** Plain JSX (No TypeScript)
- **Routing:** React Router v6
- **Animation:** Framer Motion (`useScrollReveal`, `useCounter` custom hooks)
- **Icons:** `lucide-react`
- **Styling:** Tailwind CSS + custom CSS tokens
- **Mock Backend:** `localStorage` CRUD for Portfolio, Case Studies, Enquiries & Auth Session
